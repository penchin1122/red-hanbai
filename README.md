# ReD 販売記録

ReDのリカバリーウェア販売員用のスマホアプリ（PWA）。

- 接客カウンター（声かけ・接客・デモ体験・サンプル体験・誘導・チラシ配布）
- 販売記録（商品・数量・年代・性別・リピート／ギフト／他社からの切り返し・購入理由）
- 購入に至らなかった接客の記録
- 出勤時の欠品チェック（商品ごとの色×サイズ表）
- 業務終了と、日報フォーム68項目を番号付きで並べた Claude in Chrome 用データの出力
- 分析（接客の流れ、売れた商品、年代・性別、時間帯など）

記録は端末のブラウザ内（localStorage）にだけ保存され、外部には送信されません。

## 公開
GitHub Pages で `main` ブランチのルートを公開すると、そのURLをスマホで開き「ホーム画面に追加」でアプリとして使えます。
